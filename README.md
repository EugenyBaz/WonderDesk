## 🧩 Описание

WonderDesk — это мини-платформа для публикации контента.  
Публикация может быть бесплатной, доступной любому пользователю без регистрации,
либо платной, доступной только авторизованным пользователям, которые оплатили разовую подписку.
Для реализации оплаты подписки использован Stripe. 
Регистрация пользователя реализована по номеру телефона.

## 🛠 Установка и запуск

###  1. Локальный запуск

Клонируем проект
git clone https://github.com/EugenyBaz/WonderDesk.git
cd wonderdesk

Устанавливаем зависимости через Poetry:
poetry install

Создаём .env (на основе .env.example):
copy .env.example .env

Применяем миграции и запускаем сервер:
poetry run python manage.py migrate
poetry run python manage.py runserver

После этого проект будет доступен по адресу:
👉 http://127.0.0.1:8000/
